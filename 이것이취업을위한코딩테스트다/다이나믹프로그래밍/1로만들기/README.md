## 1로 만들기
정수 X가 주어질 때 정수 X에 사용할 수 있는 연산은 다음과 같이 4가지이다.
<br/>
<br/>

1. X가 5로 나누어 떨어지면, 5로 나눈다.
2. X가 3으로 나누어 떨어지면, 3으로 나눈다.
3. X가 2로 나누어 떨어지면, 2로 나눈다.
4. X에서 1을 뺀다.
<br/>
<br/>

정수 X가 주어졌을 때, 연산 4개를 적절히 사용해서 1을 만들려고 한다. 연산을 사용하는 횟수의 최솟값을 출력하시오.

[입력 조건]

- 첫째 줄에 정수 X가 주어진다. (1 <= X <= 30,000)
<br/>
<br/>

[출력 조건] 

- 첫째 줄에 연산을 하는 횟수의 최솟값을 출력한다.

[입력 예시] <br/>
26 <br/>
<br/>

[출력 예시] <br/>
3 <br/>

풀이 시간: 20분 초과
예시 문제 소요 시간: 

## 어려웠던 점 및 알게된 점
- 아직 어떤 값을 다이나믹 리스트에 담아야 할지 감이 잘 오지 않았다. 
- 감이 잘 오지 않으면 그림으로 그려 파악하는 것이 이해가 잘 될 듯 하다.
- 특히 다이나믹 프로그래밍 문제는 문제에서 요구하는 내용을 **점화식**으로 표현해보는 게 중요한 것 같다.
