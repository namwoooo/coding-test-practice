## 위에서 아래로 
하나의 수열에는 다양한 수가 존재한다. 이러한 수는 크기에 상관없이 나열되어 있다. 이 수를 큰 수부터 작은 수의 순서로 정렬해야 한다. 내림차순으로 정렬하는 프로그램을 만드시오.
<br/>
<br/>

[입력 조건]

- 첫째 줄에 수열에 속해 있는 개수 N이 주어진다. (1 <= N <= 500)
- 둘째 줄부터 N + 1번째 줄까지 N개의 수가 입력된다. 수의 범위는 1이상 100000 이하의 자연수이다.

[출력 조건] 

- 입력으로 주어진 수열이 내림차순으로 정렬된 결과를 공백으로 구분하여 출력한다. 동일한 수의 순서는 자유롭게 출력해도 괜찮다.

[입력 예시] <br/>
3 <br/>
15 <br/>
27 <br/>
12 <br/>

풀이 시간: 10분 14초
예시 문제 소요 시간: 0.0001742839813232422

## 어려웠던 점 및 알게된 점
- 원래는 퀵 정렬로 구현하려고 했는데 기억이 안 나서 계수 정렬로 구현했다. (범위가 충족해서)
