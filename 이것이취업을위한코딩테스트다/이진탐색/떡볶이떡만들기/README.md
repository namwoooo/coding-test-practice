## 떡볶이 떡 만들기
절단기에 높이(H)를 지정하면 줄지어진 떡을 한 번에 절단한다. 높이가 H보다 긴 떡은 H 위의 부분이 잘릴 것이고, 낮은 떡은 잘리지 않는다.
<br/>
<br/>

예를 들어 높이가 19, 14, 10 17cm인 떡이 나란히 있고 절단기 높이를 15cm로 지정하면 자른 뒤 떡의 높이는 15, 14, 10, 15cm가 되고, 손님은 4, 0, 0, 2cm 즉 총 6cm만큼의 길이를 가져간다.
<br/>
<br/>

손님이 왔을 때 요청한 총 길이가 M일 때 적어도 M만큼의 떡을 얻기 위해 절단기에 설정할 수 있는 높이의 최댓값을 구하는 프로그램을 작성하시오.

<br/>
<br/>

[입력 조건]

- 첫째 줄에 떡의 개수 N과 요청한 떡의 길이 M이 주어진다. (1 <= N <= 1,000,000, 1 <= M <= 2,000,000,000)
- 두 번째 줄에는 떡의 개별 높이가 주어진다. 떡 높이의 총합은 항상 M 이상으로, 손님은 필요한 양만큼 떡을 사갈 수 있다. 높이는 10억보다 작거나 같은 양의 정수 또는 0이다.
<br/>
<br/>

[출력 조건] 

- 적어도 M만큼의 떡을 집에 가져가기 위해 절단기에 설정할 수 있는 높이의 최댓값을 출력한다.

[입력 예시] <br/>
4 6 <br/>
19 15 10 17 <br/>

<br/>
<br/>

[출력 예시]
15 
<br/>
<br/>

풀이 시간: 40분 초과

## 어려웠던 점 및 알게된 점
- mid를 중간 길이로 설정해서 이진 탐색을 이용해 범위를 절반씩 줄여 나가면 될 것이라는 접근은 맞았지만, 구현 과정에서 문제가 있었다.
- start, end는 기본 이진 탐색과 다르게 **떡의 길이**로 설정해야 한다.
- 재귀 함수로 호출하기 보다 반복문으로 작성하는 것이 간결하게 작성할 수 있다. 
- 기본 알고리즘에서 어떤 값을 문제에 맞는 값으로 수정할지 더 잘 고민해봐야 할 것 같다.
