## 바닥 공사
가로의 길이가 N, 세로의 길이가 2인 직사각형 형태의 얇은 바닥이 있다. 태일이는 이 얇은 바닥을 1 x 2의 덮개, 2 x 1의 덮개, 2 x 2의 덮개를 이용해 채우고자 한다.
<br/>
<br/>

이때 바닥을 채우는 모든 경우의 수를 구하는 프로그램을 작성하시오. 예를 들어 2 x 3 크기의 바닥을 채우는 경우의 수는 5가지 이다.
<br/>
<br/>

[입력 조건]

- 첫째 줄에 N이 주어진다. (1 <= N <= 1,000)
<br/>
<br/>

[출력 조건] 

- 첫째 줄에 2 x N 크기의 바닥을 채우는 방법의 수를 796,796으로 나눈 나머지를 출력한다.

[입력 예시] <br/>
3 <br/>
<br/>

[출력 예시] <br/>
5 <br/>

풀이 시간: 20분 초과
예시 문제 소요 시간: 

## 어려웠던 점 및 알게된 점
- 다이나믹 프로그래밍 문제는 보통 `d[i - 1]`, `d[i - 2]`를 기반으로 `d[i]`를 구하는 문제가 출제되는 것 같다.
- 이번 문제에서도 i-1까지 채워져 있을 때의 경우의 수 + i-2까지 채워져 있을 때의 경우의 수로 점화식을 세울 수 있다.
