## 왕실의 나이트
행복 왕국의 왕실 정원은 체스판과 같은 8x8 좌표 평면이다. 왕실 정원의 특정한 한 칸에 나이트가 서 있다. <br/>

나이트는 말을 타고 있어 이동을 할 때 L자 형태로만 이동할 수 있으며 정원 밖으로는 나갈 수 없다. 나이트는 특정한 위치에서 다음과 같은 2가지 경우로 이동할 수 있다.
<br/>

1. 수평으로 두 칸 이동한 뒤에 수직으로 한 칸 이동하기
2. 수직으로 두 칸 이동한 뒤에 수평으로 한 칸 이동하기
<br/> 

[입력 예시] <br/>
a1 <br/>

[출력 예시] <br/>
2 <br/>

풀이 시간: 19분
예시 문제 소요 시간: 3.528594970703125e-05
solution 소요 시간: 4.696846008300781e-05

## 어려웠던 점 및 알게된 점
- **`ord()`** 를 사용하면 하나의 유니코드 문자를 입력받아 이에 해당하는 정수값으로 변경해준다.
- 하나의 리스트에 모든 경우의 수에 대한 좌표 연산을 담아둔 후 반복문을 통해 처리하면 더 간단하게 작성할 수 있다.
