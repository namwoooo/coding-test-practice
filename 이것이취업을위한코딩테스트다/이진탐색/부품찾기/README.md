## 부품 찾기  
동빈이네 전자 매장에는 부품이 N개가 있다. 각 부품은 정수 형태의 고유한 번호가 있다. 어느 날 손님이 M개 종료의 부품을 대량으로 구매하겠다며 당일 날 견적서를 요청했다. 동빈이는 때를 놓치지 않고 손님이 문의한 부품 M개 종류를 모두 확인해 견적서를 작성해야 한다. 이때 가게 안에 부품이 모두 있는지 확인하는 프로그램을 작성해보자.
<br/>
<br/>

[입력 조건]

- 첫째 줄에 정수 N이 주어진다. (1 <= N <= 1,000,000)
- 두 번째 줄에 공백으로 구분하여 N개의 정수가 주어진다. 이때 정수는 1보다 크고 1,000,000 이하이다.
- 세 번째 줄에는 정수 M이 주어진다. (1 <= M <= 100,000)
- 네 번째 줄에는 공백으로 구분하여 M개의 정수가 주어진다. 이때 정수는 1보다 크고 1,000,000 이하이다.
<br/>
<br/>

[출력 조건] 

- 첫째 줄에 공백으로 구분하여 각 부품이 존재하면 yes를, 없으면 no를 출력한다.

[입력 예시] <br/>
5 <br/>
8 3 7 9 2 <br/>
3 <br/>
5 7 9 <br/>

풀이 시간: 11분 2초
예시 문제 소요 시간: 2.3126602172851562e-05

## 어려웠던 점 및 알게된 점
- `sort()`와 이진 탐색을 사용하면 시간 복잡도가 O((M + N) x logN)이다.
- result에 값을 저장하지 않고 바로 출력해도 괜찮다.
- 계수 정렬이나 집합(`set()`) 함수를 사용할 수도 있다. 특히 집합 함수는 단순히 특정한 데이터가 존재하는지 검사할 때 매우 효과적이다.
