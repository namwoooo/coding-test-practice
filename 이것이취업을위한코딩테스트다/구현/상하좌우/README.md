## 상하좌우
여행가 A는 N x N 크기의 정사각형 공간 위에 서있다. 가장 왼쪽 위 좌표는 (1, 1)이며, 가장 오른쪽 아래의 좌표는 (N, N)이다. 여행자 A는 상(U), 하(D), 좌(L), 우(R)로 이동할 수 있으며, 시작 좌표는 항상 (1, 1)이다. 

<br/>
<br/>
이때 여행가 A가 N x N 크기의 정사각형 공간을 벗어나는 움직임은 무시한다. 예를 들어 (1, 1)의 위치에서 L 혹은 U를 만나면 무시한다.
<br/>
<br/>
계획서가 주어졌을 때 여행가 A가 최종적으로 도착할 지점의 좌표를 출력해라.

[입력 예시] <br/>
5 <br/>
R R R U D D <br/>

풀이 시간: 7분
예시 문제 소요 시간: 1.5020370483398438e-05
